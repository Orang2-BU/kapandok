# Screenshot web KapanDok untuk proposal

Semua gambar memakai **data simulasi** (bukan data RS AR Fachrudin UMS) dan sudah memakai logo baru. Resolusi 2× (tajam saat dicetak). Diambil 12 Oktober 2026 dari web mockup Fase 0.

| File | Halaman | Kenapa penting | Keterangan gambar |
